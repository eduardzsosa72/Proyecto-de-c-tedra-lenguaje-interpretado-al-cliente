¿Qué es Chart.js?

Es una librería de código abierto que dibuja gráficos sobre un elemento <canvas>. Los gráficos son interactivos (tooltips, leyenda que oculta series), animados y se adaptan al tamaño de la pantalla.

Funciones que se prueban

  • type: "bar" con dos series (ingresos y egresos).
  • scales.x.stacked: cambiar a barras apiladas.
  • indexAxis: "y": barras horizontales.
  • tooltip.callbacks.label: mostrar montos con formato $.
  • chart.update(): redibujar sin crear el gráfico de nuevo.

Código principal

const grafico = new Chart(document.getElementById("grafico-barras"), {
    type: "bar",
    data: {
        labels: ["Jul", "Ago", "Sep", "Oct"],
        datasets: [
            { label: "Ingresos", data: [450, 380, 520, 1500], backgroundColor: "#2e9e4f" },
            { label: "Egresos",  data: [280, 410, 320, 543],  backgroundColor: "#e3350d" }
        ]
    },
    options: {
        responsive: true,
        maintainAspectRatio: false,
        plugins: {
            tooltip: {
                callbacks: { label: (ctx) => ctx.dataset.label + ": $ " + ctx.parsed.y }
            }
        }
    }
});

// Cambiar a barras apiladas
grafico.options.scales.x.stacked = true;
grafico.options.scales.y.stacked = true;
grafico.update();
