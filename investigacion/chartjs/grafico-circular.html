Distribución del pago de servicios

Prueba de concepto del gráfico circular que mostrará qué porcentaje del dinero se fue en cada servicio durante el mes.

Demostración: octubre 2026

Haz clic en un servicio de la leyenda para quitarlo; los porcentajes se recalculan solos.

Datos utilizados

ServicioMonto%

¿Por qué un gráfico circular?

Sirve para mostrar partes de un total. Aquí el total es lo pagado en servicios y cada porción es un servicio. Con pocas categorías (4) se lee con facilidad.

Funciones que se prueban

  • type: "doughnut" y type: "pie".
  • cutout: tamaño del hueco central de la dona.
  • Tooltip que calcula el porcentaje de cada servicio.
  • Plugin propio que escribe el total en el centro de la dona.
  • chart.config.type + update(): cambiar de tipo.

Plugin del total central

Chart.js permite crear plugins que dibujan sobre el canvas. El plugin totalCentro usa el hook afterDraw para escribir el total pagado en el centro, sumando solo los servicios visibles.

Código principal

new Chart(document.getElementById("grafico-circular"), {
    type: "doughnut",
    data: {
        labels: ["Energía eléctrica", "Internet", "Telefonía", "Agua potable"],
        datasets: [{
            data: [85, 45, 35, 28],
            backgroundColor: ["#ffcb05", "#2a75bb", "#2e9e4f", "#e3350d"]
        }]
    },
    options: {
        cutout: "60%",
        plugins: {
            tooltip: {
                callbacks: {
                    label: (ctx) => {
                        const total = ctx.dataset.data.reduce((a, b) => a + b, 0);
                        const pct = (ctx.parsed / total * 100).toFixed(1);
                        return `${ctx.label}: $ ${ctx.parsed} (${pct}%)`;
                    }
                }
            }
        }
    }
});
