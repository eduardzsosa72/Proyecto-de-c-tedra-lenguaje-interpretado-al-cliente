Comprobante de retiro en PDF

Prueba de concepto del ticket que el cajero entregará al finalizar un retiro. El PDF se genera directamente en el navegador, sin servidor.

¿Qué es jsPDF?

Es una librería de JavaScript para crear documentos PDF desde el navegador. Permite escribir texto, dibujar líneas y rectángulos, insertar imágenes y elegir el tamaño de la hoja.

Funciones que se prueban

  • new jsPDF({ format: [80, 160] }): hoja tamaño ticket (80 mm).
  • text(), setFont(), setFontSize(): escribir datos.
  • rect(), line(), setFillColor(): encabezado y separadores.
  • save(): descargar el archivo.
  • output("bloburl"): ver el PDF antes de descargarlo.

Código principal

const { jsPDF } = window.jspdf;

// Hoja de 80 mm x 160 mm (tamaño de ticket de cajero)
const doc = new jsPDF({ unit: "mm", format: [80, 160] });

doc.setFillColor(227, 53, 13);          // rojo Pokémon Bank
doc.rect(0, 0, 80, 22, "F");
doc.setTextColor(255, 255, 255);
doc.setFont("helvetica", "bold");
doc.setFontSize(14);
doc.text("POKÉMON BANK", 40, 12, { align: "center" });

doc.setTextColor(30, 30, 30);
doc.setFontSize(9);
doc.text("Monto retirado:", 6, 60);
doc.text("$ 100.00", 74, 60, { align: "right" });

doc.save("comprobante-retiro.pdf");
