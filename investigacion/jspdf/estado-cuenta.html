Estado de cuenta en PDF

Prueba de concepto del estado de cuenta mensual: un documento tamaño carta con los datos del cliente, un resumen y la tabla de movimientos.

¿Qué se agrega?

jsPDF por sí solo no dibuja tablas. Para eso se usa el plugin jspdf-autotable, que convierte un arreglo de datos en una tabla con encabezado, colores, alineación y salto de página automático.

Funciones que se prueban

  • new jsPDF({ format: "letter" }): hoja tamaño carta.
  • doc.autoTable({ head, body }): tabla de movimientos.
  • headStyles y columnStyles: colores y montos alineados a la derecha.
  • didDrawPage: pie de página con número de página.
  • doc.lastAutoTable.finalY: escribir debajo de la tabla.

Código principal

const doc = new jsPDF({ unit: "mm", format: "letter" });

doc.autoTable({
    startY: 70,
    head: [["Fecha", "Tipo", "Descripción", "Monto", "Saldo"]],
    body: filas,                                   // arreglo de arreglos
    headStyles: { fillColor: [227, 53, 13] },      // rojo Pokémon Bank
    columnStyles: { 3: { halign: "right" }, 4: { halign: "right" } },
    didDrawPage: (data) => {
        doc.text("Página " + data.pageNumber, 196, 270, { align: "right" });
    }
});

const y = doc.lastAutoTable.finalY + 10;           // debajo de la tabla
doc.text("Saldo final: $ 2,457.00", 196, y, { align: "right" });
doc.save("estado-cuenta.pdf");
