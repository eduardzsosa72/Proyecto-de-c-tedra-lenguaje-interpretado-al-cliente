Confirmación antes de retirar

Ejemplo 2 de SweetAlert: el cuadro de confirmación que aparece antes de descontar dinero de la cuenta, para evitar retiros por error.

¿Por qué confirmar?

Un retiro no se puede deshacer. SweetAlert permite mostrar un modal con dos botones y devuelve una promesa: el valor es true si el usuario confirmó y null si canceló. Así el código solo continúa si el usuario acepta.

Funciones que se prueban

  • buttons: ["Cancelar", "Sí, retirar"]: dos botones.
  • dangerMode: true: el botón de confirmar se pinta de rojo.
  • .then(valor => ...): lee la decisión del usuario.
  • closeModal: false y swal.stopLoading(): espera mientras se "procesa" el retiro.
  • Mensaje de error cuando el saldo no alcanza.

Código principal

swal({
    title: "¿Confirmar retiro?",
    text: "Vas a retirar $ 100.00",
    icon: "warning",
    dangerMode: true,
    buttons: {
        cancel: "Cancelar",
        confirm: { text: "Sí, retirar", closeModal: false }   // muestra la carga
    }
}).then((confirmado) => {
    if (!confirmado) {
        swal("Operación cancelada", "No se realizó ningún cargo.", "info");
        return;
    }
    // Simula el tiempo que tarda el cajero
    setTimeout(() => {
        swal.stopLoading();
        swal("Retiro realizado", "Retira tu efectivo de la bandeja.", "success");
    }, 1200);
});
