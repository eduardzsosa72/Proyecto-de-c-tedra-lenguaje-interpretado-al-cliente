Notificación de transacción exitosa

Ejemplo 1 de SweetAlert: cómo el cajero muestra un mensaje de éxito después de un depósito o del pago de un servicio.

¿Qué es SweetAlert?

Es una librería de JavaScript que reemplaza el alert() del navegador por ventanas modales atractivas y personalizables. Se usa con una sola función, swal(), que devuelve una promesa con el botón que presionó el usuario.

¿Para qué la usaremos?

  • Confirmar que un depósito se realizó correctamente.
  • Avisar que el pago de un servicio fue aplicado.
  • Mostrar errores, por ejemplo un monto inválido.
  • Mostrar avisos que se cierran solos con timer.

Cómo se incluye

<script src="https://cdn.jsdelivr.net/npm/sweetalert@2.1.2/dist/sweetalert.min.js"></script>

Demostración: depósito

Titular Brock Harrison
Saldo actual $ 2,457.00

Prueba con un monto válido, con un monto vacío o negativo y con el botón de pago para ver el aviso que se cierra solo.

Código principal

// Alerta de éxito: swal(título, texto, icono)
swal("Depósito exitoso", "Se depositaron $ 100.00 a tu cuenta.", "success");

// Con objeto de opciones y texto del botón
swal({
    title: "Depósito exitoso",
    text: "Nuevo saldo: $ 2,557.00",
    icon: "success",
    button: "Aceptar"
});

// Aviso que se cierra solo después de 2 segundos (sin botones)
swal({
    title: "Pago de energía aplicado",
    icon: "success",
    buttons: false,
    timer: 2000
});
