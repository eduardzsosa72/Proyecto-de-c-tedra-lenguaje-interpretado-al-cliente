Validación de montos

Prueba de concepto de las reglas que debe cumplir un monto antes de procesar un depósito, un retiro o el pago de un servicio.

Reglas según la operación

OperaciónReglas
Depósito Mayor a $ 0 y máximo $ 1,000 por operación.
Retiro Múltiplo de $ 5 (billetes), máximo $ 500 y no mayor al saldo.
Servicio Mayor a $ 0 y no mayor al saldo.

En todas: el campo es obligatorio, debe ser un número y tener como máximo 2 decimales.

Funciones que se prueban

  • numericality con greaterThan, lessThanOrEqualTo y divisibleBy.
  • format: máximo 2 decimales.
  • Reglas que cambian según la operación (función que arma las reglas).
  • Mensajes personalizados en español.

Código principal

function reglasRetiro(saldo) {
    return {
        monto: {
            presence: { allowEmpty: false, message: "^Ingresa un monto" },
            format: {
                pattern: "^-?\\d+(\\.\\d{1,2})?$",
                message: "^Ingresa un número válido con máximo 2 decimales"
            },
            numericality: {
                greaterThan: 0,
                lessThanOrEqualTo: Math.min(500, saldo),
                divisibleBy: 5,
                notGreaterThan: "^El monto debe ser mayor a $ 0",
                notLessThanOrEqualTo: "^El monto supera el límite permitido",
                notDivisibleBy: "^El cajero solo entrega múltiplos de $ 5"
            }
        }
    };
}

const errores = validate({ monto: "47" }, reglasRetiro(2457), { fullMessages: false });
// => { monto: ["El cajero solo entrega múltiplos de $ 5"] }
