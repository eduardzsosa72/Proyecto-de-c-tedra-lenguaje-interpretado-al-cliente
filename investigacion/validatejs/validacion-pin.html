Reglas de validación del PIN

Prueba de concepto de cómo validar el PIN de 4 dígitos: tanto al iniciar sesión como al crear o cambiar el PIN de la tarjeta.

¿Qué es validate.js?

Es una librería que valida datos a partir de un objeto de reglas (constraints). En lugar de escribir muchos if, se declara qué debe cumplir cada campo y la función validate() devuelve los errores encontrados, o undefined si todo está bien.

Reglas aplicadas al PIN

  • presence: el campo no puede estar vacío.
  • length: { is: 4 }: exactamente 4 caracteres.
  • format: solo números (^[0-9]{4}$).
  • exclusion: no se permiten PIN fáciles como 0000 o 1234 (solo al crear PIN).
  • equality: la confirmación debe ser igual al PIN nuevo.

Demostración: crear PIN

Pruebas rápidas

Los errores también se muestran mientras escribes, al salir de cada campo.

Código principal

const reglas = {
    pin: {
        presence: { allowEmpty: false, message: "^Ingresa tu PIN" },
        length:   { is: 4, wrongLength: "^El PIN debe tener exactamente 4 dígitos" },
        format:   { pattern: "^[0-9]{4}$", message: "^El PIN solo puede contener números" },
        exclusion:{ within: ["0000", "1111", "1234", "4321"], message: "^Ese PIN es muy fácil de adivinar" }
    },
    confirmacion: {
        presence: { allowEmpty: false, message: "^Confirma tu PIN" },
        equality: { attribute: "pin", message: "^Los PIN no coinciden" }
    }
};

const errores = validate({ pin: "0000", confirmacion: "0000" }, reglas, { fullMessages: false });
// => { pin: ["Ese PIN es muy fácil de adivinar"] }
